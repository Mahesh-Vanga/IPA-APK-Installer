# Security policy

Report suspected security issues privately through the repository’s Security tab when private vulnerability reporting is available. Do not post exploitable details or attach private files in a public issue. A useful report includes the release version, the affected behavior, and the impact. Share the minimum necessary evidence.

The app runs locally with the current user's permissions. Install only builds you trust, and use Xcode and Android Platform-Tools from their official publishers. Device operating systems enforce their own signing and installation policies.
