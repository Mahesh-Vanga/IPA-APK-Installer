# Changelog

## 0.0.1

- Consolidates the optimized preview into the only supported public release.
- Ships a universal Developer ID-signed and notarized DMG and PKG, with SHA-256 checksums.
- Hands the menu bar icon to a fresh process after use to release memory. Preserves the selected package, device, and diagnostics.
- Includes Finder IPA/APK drops, a detachable panel, configurable close timing, launch at login, offline local installation, and optional manual update checks.
- Publishes the complete MIT-licensed source, tests, build instructions, and an app screenshot gallery.

If replacing a build labeled 0.0.2 or 0.0.3, quit it fully and install 0.0.1 manually. The app’s update check does not offer versions with a lower public version number.
